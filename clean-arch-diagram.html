🎯
Regra da Dependência
Dependências sempre apontam para dentro. domain nunca importa infra ou presentation.
🔒
@Entity isolada
TaskJpaEntity fica em infra/jpa. O domínio usa Task pura, sem anotações JPA.
🧪
Testes sem Spring
Task e use cases são testáveis com new Task.create() — zero mock de framework.
🔄
Trocar ORM
InMemory ↔ JPA ↔ JDBC via @Primary no adapter. Zero mudança em domain e application.
📦
@Service proibido
Use cases são POJO. O Spring os conhece apenas via @Bean no BeanConfiguration.
🚫
@Entity no domínio
O pacote domain/ nunca deve conter anotações JPA, Spring ou qualquer framework.
